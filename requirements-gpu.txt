# Version pins for the GPU box.
#
# The box installs from this file, not from the ranges in pyproject.toml. Ranges are right for a library and
# wrong for a rented machine: a transformers release between the rehearsal and the day turns an eight-hour
# session into a debugging session. `agentdistill train` already carries a compatibility shim for one such
# break (transformers 5.x removed `warmup_ratio`); the point of pinning is not to need a second one.
#
#   pip install -r requirements-gpu.txt -e ".[train,serve]"
#
# Regenerate after a green tiny rehearsal:
#   uv pip freeze | grep -iE '^(torch|transformers|trl|peft|accelerate|datasets|tokenizers|safetensors|numpy|scikit-learn|scipy)=='
#
# ---------------------------------------------------------------------------------------------------------

# ---------------------------------------------------------------------------------------------------------
