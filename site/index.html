agentdistill

Distil a tool-using agent's teacher model into a small student, and serve the two as a cost-aware cascade: the student answers, and a calibrated gate escalates the turns it is not confident about.

No model has been trained yet. Every number on the linked report comes from the CPU rehearsal, which runs the whole pipeline against a randomly-initialised two-layer model and a replay stub standing in for the teacher. It measures that the pipeline executes, and nothing else. The report says so on its own first line, and names each claim it cannot make.

What it does

StageWhat happens
ingest, curate Recorded agent trajectories are filtered, de-duplicated, decontaminated against the eval sets, and clustered into a content-hashed dataset.
train sft, train onpolicy LoRA supervised fine-tuning, then rejection sampling and DPO on the student's own failures. A round is kept only if a paired comparison says it helped.
eval Every subject runs the same held-out tasks against the real environment and is graded on the state it left behind, with task-clustered intervals.
calibrate Fits the confidence gate on turns the student got right or wrong, reports its reliability on a task-disjoint holdout, and refuses a gate that carries no signal.
serve An OpenAI- and Anthropic-compatible gateway. The agent keeps its SDK and its model name; routing, escalation and the cascade are invisible to it.
report One HTML file and a JSON sidecar. Every number carries the run id that produced it.

The rule the project is built around

A stage that produces nothing must not look like a stage that produced something uninteresting. So: a stage that writes no row exits 3 and the pipeline stops; a comparison below 20 tasks by 3 repeats returns its reason instead of statistics, and no renderer may print a p-value beside it; a missing measurement becomes a named warning rather than a blank or a zero; and every promotion gate fails closed when the evidence is missing.

Running it yourself

The whole pipeline runs on a laptop with no GPU, no API key and no network, against a generated corpus and a tiny local model:

git clone https://github.com/ChariPramod/agentdistill
cd agentdistill && pip install -e ".[dev,train,serve]"
bash scripts/clean_rehearsal.sh

That destroys every artifact, reruns all eighteen stages from nothing, and asserts the report it produced: the subjects present, the sections populated, and no warning outside the ones tiny mode is expected to raise.
